# Study Planner

Study Planner is a simple web application for organizing study tasks. It was created as a beginner project using HTML, CSS, and JavaScript.

## Features

- Add new study tasks
- Mark tasks as completed
- Delete tasks
- Filter all, active, and completed tasks
- Count remaining tasks
- Save tasks in the browser
- Use the application on desktop and mobile screens

## Technologies

- HTML5 for the page structure
- CSS3 for styling and responsive design
- JavaScript for the application logic
- Local Storage for saving tasks

## How to run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with Live Server or directly in a web browser.

## Project structure

- `index.html` contains the page structure.
- `style.css` contains the visual styles.
- `script.js` contains the task management logic.
